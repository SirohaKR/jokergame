# 캐릭터별 이모티콘

2026-11-05. 사용자 예시는 작은 카드게임 스티커의 표정·동작 가독성 참고이며, 예시 캐릭터의 외형을 복제하지 않는다. 신규 전신의 머리·눈·의상·밝은 피부색을 기준으로 한다.

각 캐릭터별 PNG는 2×2 아틀라스. 좌상 웃음, 우상 당황, 좌하 인사, 우하 의심이다. 얼굴과 손을 크게 보여 주는 상반신 치비 표현으로 제작한다. 대사는 이미지에 굽지 않고 UI에 표시한다.

| 캐릭터 | 웃음 | 당황 | 인사 | 의심 |
|---|---|---|---|---|
| 세레나 | 입가에 손을 댄 능청스러운 웃음 | 여유가 깨지고 어깨가 굳음 | 윙크하며 작은 손인사 | 턱을 짚고 옆눈으로 살핌 |
| 엘리시아 | 손을 가슴에 모은 수줍은 웃음 | 두 손을 들고 허둥댐 | 케이프 뒤에서 빼꼼 인사 | 공상 속 탐정처럼 진지하게 추리 |
| 루네아 | 소매에 뺨을 기대고 만족 | 잠이 확 깬 큰 눈 | 하품하며 느린 손인사 | 소매 속에 파묻힌 무심한 의심 |
| 로제트 | 주먹을 들고 크게 환호 | 양 볼을 잡는 과장된 당황 | 몸을 기울여 크게 손 흔듦 | 볼을 부풀리고 허리에 손 |

피부는 밝은 아이보리에 옅은 분홍 홍조만 허용한다. 놀람을 표현하기 위해 얼굴 전체를 파랑/회색으로 물들이지 않는다. 소품과 이펙트는 최소화하고 동작의 차이로 개성을 만든다.

기존 공개 이모티콘 3초 쿨다운, 2초 노출, 조커 자동 연출의 당사자 전용 규칙을 유지한다. 공개 웃음과 조커를 넘겼을 때의 사적 반응은 같은 이미지여도 서로 다른 전송/표시 규칙을 따른다.

## 적용 및 검증

2026-11-06: 드라이브 `조커게임/1차작업/이모티콘`의 사용자 PixAI 스티커 16장으로 교체했다(파일 번호 1 웃음, 2 당황, 3 인사, 4 의심). 원본은 1408×1408 흰 배경이다.

- 배경 투명화는 알파 채널만 바꿨다. 이미지 가장자리와 이어진 거의 흰색 영역(min RGB ≥ 236)만 투명하게 만들고, 스티커 외곽선이 흐려 배경이 새어 들어간 곳은 메워서 흰 스티커 테두리를 보존했다. RGB는 수정하지 않았다.
- 캐릭터별로 각 칸을 640×640으로 줄여 1280×1280 2×2 아틀라스 한 장으로 저장했다. CSS 좌표와 저장 프로필/API ID는 그대로다.
- Chromium에서 16종 갤러리와 게임 중 이모티콘 전송을 확인했다. 어두운 배경 위에서도 배경 잔여물 없이 흰 테두리만 남는다.
- 장식(반짝이, 꽃 링, 땀방울 등)은 스티커 밖에 떠 있어도 흰색이 아니면 유지된다.

이전(이미지 생성 기반) 아틀라스는 git 이력에 남아 있다.
