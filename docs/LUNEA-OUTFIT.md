# 루네아 의상 — 달구름의 낮잠

최신 기준: 사용자가 제공한 루네아 변경 프롬프트. [설정집](CHARACTERS.md) · [복사용 프롬프트](CHARACTER-DESIGN.md)

## 얼굴과 머리

19세 인간 소녀. 밀크티 베이지색의 풍성하고 약간 흐트러진 웨이브 장발, 낮고 느슨한 옆머리 땋기, 잔머리 한 가닥, 가벼운 앞머리. 눈은 청회색이며 처진 눈꼬리와 반쯤 감긴 눈꺼풀로 나른함을 표현한다. 얼굴은 부드럽고 앳되며 입가는 편안하게 미소 짓는다.

더스티 블루 수면안대는 눈을 덮지 않고 머리띠처럼 머리 위로 올린다. 작은 은색 초승달 자수는 안대에만 넣는다. 기존의 초승달 머리핀·케이프·달 보석·치맛단 장식을 대체한다.

## 의상

- 더스티 블루 오버사이즈 니트 카디건을 느슨하게 입는다. 소매는 손목보다 길지만 손끝이 보인다.
- 우윳빛 아이보리색의 여유 있는 무릎길이 원피스. 허리는 부드러운 잔주름, 칼라는 낮고 둥글며 작은 연하늘색 리본 하나를 둔다.
- 진주색 양말은 발목 주변에 자연스럽게 주름이 모인다. 아이보리색 둥근 메리제인 슈즈를 신는다.
- 색은 밀크티 베이지·아이보리·더스티 블루를 중심으로 한다. 크고 포근한 실루엣과 적은 장식으로 느긋한 살롱 단골의 인상을 만든다.

직업은 달빛 결계사로 유지한다. 이번 의상은 주점에서 쉬는 일상복이며 직업용 케이프나 전투 장비를 자동으로 추가하지 않는다.

## 변경 이유 — 사용자 디자인 의도

| 부분 | 기존 | 변경 | 이유 |
|---|---|---|---|
| 시그니처 | 초승달 헤어핀 | 이마 위로 올린 수면안대, 작은 초승달 자수 | 보자마자 느긋한 성격이 읽히는 대표 소품. 달 모티프도 자연스럽게 이어진다. |
| 머리 | 단정한 옆 땋은 머리 | 푸석하고 풍성한 웨이브, 느슨한 땋은 머리, 바보털 하나 | 방금 일어난 느낌을 머리 형태로 표현한다. |
| 눈 | 둥근 반감은 눈 | 처진 눈매(타레메)와 반감은 눈 | 세레나의 올라간 눈매와 대비되어 나란히 서면 성격이 구분된다. |
| 상의 | 짧은 하늘색 케이프와 뒤 리본 | 오버사이즈 니트 카디건 | 크고 느슨한 실루엣으로 느긋함을 표현한다. |
| 소매 | 손목에서 모은 소매 | 손등을 덮는 긴 소매, 손끝만 보임 | 귀여움을 더하고 손 노출을 줄이려는 의도. 생성 오류 감소 여부는 실제 결과에서 확인한다. |
| 치마 | 주름 A라인과 초승달 장식 세 개 | 허리를 느슨하게 모은 원피스, 치마 장식 없음 | 장식을 덜어 포근한 실루엣에 집중한다. |
| 하체 | 진주색 타이츠와 앵클부츠 | 흘러내린 양말과 메리제인 | 루즈삭의 편안한 형태로 느긋한 분위기를 마무리한다. |
| 색 | 아이보리·하늘색·블루그레이 | 밀크티 베이지·아이보리·더스티 블루 | 채도를 낮춰 졸리고 포근한 분위기를 만든다. |

마지막 색 설명은 사용자 메시지에서 문장이 잘려 있어 앞선 프롬프트와 문맥에 맞게 정리했다. 이 표는 디자인 의도이며 생성 성능을 검증한 결과는 아니다.

## 생성 시 확인

사용자 Positive는 제작 가이드에 원문 그대로 저장한다. 공통 Positive의 손가락을 모두 보이게 하는 지시와 이 프롬프트의 긴 소매가 함께 있으므로 결과에서 손끝이 자연스럽게 나오는지 확인한다. 수면안대가 눈을 덮거나 머리핀으로 바뀌지 않도록 확인한다. 현행 공통 음영 지침을 사용하며 니트 질감 때문에 사진풍으로 바뀌지 않게 한다.

실제 생성 결과는 아직 확인하지 않았다.
