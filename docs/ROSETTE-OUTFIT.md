## 얼굴과 머리

18세 인간 소녀. 코랄핑크 머리를 큰 아이보리 슈슈로 높고 탄력 있게 묶는다. 옆으로 넘긴 앞머리, 짧은 옆머리, 활기 있는 잔머리 몇 가닥을 둔다. 눈은 크고 밝은 아쿠아색, 볼은 둥글고 생기 있게. 입을 벌린 환한 미소에 작은 송곳니가 보인다.

슈슈가 머리의 대표 장식이다. 기존 하트 머리핀과 여러 실핀을 추가하지 않는다.

## 의상 구성

| 부분 | 최신 디자인 |
|---|---|
| 재킷 | 짧은 아쿠아색 재킷, 소매는 팔꿈치까지 걷음 |
| 원피스 몸판 | 정돈된 코랄색 몸판, 단정한 아이보리 칼라 |
| 목 중앙 | 작은 하트 모양 보석 하나 |
| 허리 | 높은 위치의 아이보리 허리띠 |
| 치마 | 무릎 위 길이의 퍼지는 코랄 플리츠, 아쿠아색 안감 |
| 양말 | 아이보리 니삭스 |
| 신발 | 볼륨 있는 흰 앵클부츠, 아쿠아색 끈 |

상체의 재킷, 허리띠, 퍼지는 치마가 명확하게 구분되는 실루엣이다. 팔꿈치까지 걷은 소매와 포니테일로 움직임을 표현한다. 기존 퍼프소매·두 갈래 케이프·큰 허리 리본·금색 방울·타이츠는 이번 안에서 교체했다.

## 색·성격·연출

코랄·아이보리·아쿠아 세 색을 중심으로 유지한다. 작은 하트 보석 외의 장식은 최소화한다. 직업은 길드 음유시인으로 유지하며, 이 의상은 달빛 살롱의 활발한 분위기 메이커라는 최신 이미지 방향을 따른다.

인사할 때 포니테일과 플리츠 치마의 움직임을 활용한다. 스킬 연출이 필요하면 목의 하트 보석에서 음표 빛이 퍼지는 방향으로 연결한다. 제거된 방울이나 케이프에서 효과가 발생하지 않게 한다.

## 생성 확인 사항

사용자 Positive는 제작 가이드에 원문 그대로 저장했다. 범용 Negative를 함께 사용한다. 세레나 전용 Negative를 섞어 쓰지 않는다.

슈슈가 장식 여러 개로 바뀌지 않는지, 재킷과 원피스의 색이 서로 뒤바뀌지 않는지, 양말이 타이츠로 바뀌지 않는지 확인한다. 현행 공통 Positive의 음영 지침을 따른다. 실제 생성 결과는 아직 검증하지 않았다.
