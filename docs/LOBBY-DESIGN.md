# 로비와 캐릭터 화면

## 화면 구성

- 로비는 최신 `assets/lobby/` 일러스트, 대전 입구, 하단 메뉴로 구성한다. 배경은 프로젝트용으로 생성한 밝은 카드게임 라운지(`assets/backgrounds/lounge.png`)다. 큰 파트너 일러스트 위에 프로필·직접 선택하는 대전 모드·하단 오브젝트 아이콘을 배치한다. UI는 흰색·하늘색 단색 면과 또렷한 테두리를 사용하며 그라데이션·하단 페이드·추상 원형 장식은 쓰지 않는다.
- 로비 하단의 **캐릭터**는 별도 캐릭터 화면(`#characters`)으로 이동한다. 로비의 캐릭터 이름표와 프로필 내 파트너 이름은 제거했다. 플레이어 닉네임 입력은 유지한다. 로비의 별도 이모티콘 메뉴는 제거했다.
- 캐릭터 화면은 큰 일러스트, 정보 패널, 화면 너비를 사용하는 하단 캐릭터 목록, 파트너 지정 버튼으로 구성한다. 탭 없이 소개·실제 게임의 스킬 설명·웃음/당황/인사/의심 이모티콘을 함께 보여준다. 이모티콘을 누르면 해당 대사를 표시한다.
- 목록에서 캐릭터를 살펴보는 행동과 파트너 지정은 분리한다. 지정한 파트너만 프로필에 저장하고 로비·대기실·AI 대전에 적용한다.
- 일러스트 양옆 화살표, 마우스 드래그, 터치 스와이프, 일러스트에 포커스한 상태의 좌우 방향키로 이전/다음 캐릭터를 순환한다. 세로 제스처는 페이지 스크롤을 유지하며 둘러보기만으로 파트너가 변경되지 않는다.
- 목록은 얼굴이 보이는 정사각형 썸네일과 가로 스크롤을 사용한다. 캐릭터가 늘어나도 항목을 줄이지 않으며 현재 열람 캐릭터가 보이도록 목록이 따라간다. 이모티콘 조작 중에는 목록과 상세 패널의 스크롤 위치를 유지한다.
- 로비 복귀 버튼, Escape, 브라우저 뒤로/앞으로 이동을 지원한다. 모바일에서는 일러스트·가로 목록·정보 패널 순서로 배치한다.
- 제작 도구(UI 편집·UI 디자인 기획·대사 편집)는 로비 우측 더보기 메뉴에 둔다.

작혼의 캐릭터 감상·선택 화면을 참고해 일러스트와 캐릭터 목록, 상세 정보를 분리했다. 이후 사용자가 제공한 마작1번가·작혼·아스트랄파티·스텔라소라·블루아카이브 예시를 기준으로 장소 배경과 가장자리 메뉴 중심의 구성을 적용했다. 참고: [공식 Steam 페이지의 화면 자료](https://store.steampowered.com/app/1329410/MahjongSoul/). 작혼의 UI 이미지나 자산을 사용하지 않는다.

## 구현과 후속 해금 기능

- 마크업: `prototype/frontend/src/lobby-ui.js`
- 스타일: `prototype/frontend/game-hub.css`
- 화면 전환·열람 상태·지정 저장: `prototype/frontend/src/app.js`
- `viewedCharacter`는 살펴보는 캐릭터, `selectedCharacter`는 실제 파트너다.
- 현재 네 캐릭터는 모두 사용 가능하다. `CHARACTER_ACCESS`와 `canUseCharacter()`로 사용 가능 여부와 파트너 상태를 분리했으며 미해금 캐릭터는 지정할 수 없지만 정보와 이모티콘은 볼 수 있다.
- 재화·가격·구매·해금 저장은 아직 구현하지 않았다. 도입 시 사용 가능 여부를 서버의 보유 캐릭터 정보로 대체하고 구매/잔액/대전 캐릭터 선택을 서버에서 검증해야 한다. 현재 클라이언트의 정책 객체는 권한 검증 수단이 아니다.

## 확인 범위

격리된 headless Chromium에서 1920×1080, 1440×900, 1280×720, 1024×640, 390×844 화면을 확인했다. 캐릭터 열람과 지정의 분리, 화살표 순환, 키보드·마우스·터치 전환, 세로 제스처 무시, 목록의 스크롤 유지, 이모티콘 선택, 저장된 파트너의 대전 적용을 확인했다. 모바일은 세로 스크롤로 상세 정보와 지정 버튼에 접근한다.

## 게임 UI 구성과 Unity 이전 기준

현재 동작하는 웹 프로토타입의 로비와 캐릭터 화면을 개편한 상태다. Unity 프로젝트나 프리팹은 아직 생성하지 않았다. 화면 요소를 아래처럼 분리해 옮긴다.

| 영역 | 현재 요소 | Unity에서 대응할 구성 |
| --- | --- | --- |
| 배경 | `hub-backdrop` · 독립 라운지 PNG | 입력을 받지 않는 배경 이미지 레이어 |
| 캐릭터 무대 | 일러스트 · 이름판 · 좌우 탐색 | 캐릭터 표시 프리팹, 스와이프/버튼 입력 |
| 상단 정보 | 화면 제목 · 프로필 · 소리 · 돌아가기 | 상단 앵커를 사용하는 HUD |
| 대전 | 모드 소개 · 선택 목록 · 시작 버튼 | 모드 선택 패널과 버튼 상태 |
| 상세 정보 | 소개 · 스킬 · 이모티콘 · 파트너 지정 | 상세 패널, 세로 ScrollRect, 하단 고정 지정 버튼 |
| 하단 선택 | 로비 메뉴 또는 캐릭터 목록 | 하단 앵커, 가로 ScrollRect, 선택 프레임 |

- 버튼 상태는 기본·호버·눌림·선택·비활성을 구분한다. 캐릭터 해금 여부와 실제 파트너 지정 상태는 별도 데이터로 유지한다.
- 기존 남색·금색 패널, 원형 문양과 CSS 그라데이션은 제거했다. 배경은 독립 이미지 한 장이며 프로필·버튼·일러스트와 합쳐 저장하지 않는다.
- 로비에서 네 대전 모드를 바로 확인한다. AI 대전 버튼은 한 번에 대기실로 이동하고, 친구 방·단기전·3세트전은 준비 중으로 표시한다. 기존 대전 버튼을 누른 뒤 모드를 펼치는 단계는 제거했다.
- 캐릭터는 자체 이모티콘, 나머지 하단 메뉴는 프로젝트에서 정의한 단색 SVG 오브젝트 아이콘을 사용한다. 실제 기능이나 재화·등급을 암시하는 가짜 수치는 넣지 않는다.
- 얼굴은 `collectionCrops`에 지정된 캐릭터별 정사각형 영역을 사용한다. Unity 이전 시 동일한 원본 좌표로 별도 얼굴 스프라이트를 만든다.
- 패널 테두리·버튼은 9-slice 또는 벡터로, 일러스트와 이모티콘은 기존 PNG를 사용한다. 캐릭터 전환 시의 이동·페이드는 무대에만 적용한다.
- 현재 모바일은 같은 컴포넌트를 세로로 재배치한다. Unity의 고정 가로 화면/세로 지원 여부는 이전 단계에서 정한다.

## 일러스트 조정과 UI 감추기

- 게임 방법은 기존 왼쪽 위 책 아이콘과 글자 위치를 유지한다. 왼쪽 하단바 바로 위에는 크기/위치(사방 화살표)·UI 감추기 아이콘 두 개를 배치한다. 흰색 약 52% 불투명도의 정사각형 배경과 진한 아이콘으로 식별성을 확보하며 바와 간격은 6px이다. 툴팁과 접근성 이름으로 기능을 구분한다.
- `크기·위치`는 드래그·터치·방향 버튼 또는 일러스트에 포커스한 상태의 방향키로 이동하고, 60~160% 슬라이더로 확대/축소한다. 위치는 기본 이미지 크기 기준 ±40%로 제한한다.
- `저장`을 눌러야 반영한다. `취소`·Escape·화면 이동은 저장하지 않은 변경을 버린다. `기본 위치·크기`는 초안을 기본값으로 되돌린다. 저장 실패 시 편집을 유지하고 오류를 표시한다.
- `frontend/src/artwork-controls.js`가 편집 입력·표시와 저장을 담당한다. `last-one-artwork-layouts-v1` localStorage에 캐릭터 assetId와 PC/모바일 구분으로 저장한다. 프로필·파트너·게임 상태와는 독립이다.
- `UI 감추기`는 프로필·메뉴·대사·이름 등 UI를 숨기고, 작은 `UI 표시` 버튼과 Escape로 복구한다. 숨긴 UI는 키보드 포커스에서도 제외한다. 화면 이동이나 새로고침 시 정상 표시로 돌아온다.
- 로비 조정은 캐릭터 정보 화면의 탐색용 일러스트·얼굴 썸네일·대기실·대전에는 적용하지 않는다.
