# 대기실 시안 01 — 아치형 일러스트 배치

2026-11-09. 실제 AI 대전 대기실에 연결한 첫 시안. 기존 네 명의 사각 패널을 아이보리·라벤더 배경, 아치형 일러스트 영역, 얇은 장식선과 곡선형 시작 버튼으로 교체했다.

## 구성

- 로비에서 선택한 파트너를 왼쪽에 조금 크게 표시한다. AI 세 좌석은 중복 선택과 번호 표기를 유지한다.
- 이름·준비 상태·캐릭터 소개·스킬을 그림 아래에 배치한다. 이모티콘은 내 일러스트 위에 표시한다.
- PC는 네 좌석을 가로로 표시하고 1024×640에서도 시작 버튼이 화면 안에 들어간다. 모바일은 2×2 배치와 세로 스크롤을 사용한다.
- `frontend/src/waiting-room.js`가 대기실 마크업, `frontend/waiting-room.css`가 전용 스타일이다. `salon-` / `guest-` 클래스로 게임 테이블의 좌석 스타일과 분리했다.

## 대기용 일러스트 교체

현재는 기존 투명 스탠딩을 임시 사용한다. 별도 대기용 일러스트가 준비되면 `frontend/src/data.js`의 `WAITING_ARTWORK`에 캐릭터별 설정을 넣는다. 게임 중 초상화와 스킬 컷인은 바뀌지 않는다.

```js
export const WAITING_ARTWORK = {
  serena: {
    src: 'assets/lounge/serena.webp',
    position: '50% 25%',
    scale: 1,
    fit: 'cover'
  }
};
```

지원 키는 `serena`, `elysia`, `lunea`, `rosette`. 설정이 없으면 기존 스탠딩으로 돌아간다. `position`은 얼굴을 기준으로 잘리는 위치, `scale`은 확대 비율, `fit`은 `cover` 또는 `contain`이다.

- 세로형 2:3 정도의 원본을 권장한다. 투명 그림과 배경이 포함된 일러스트를 모두 사용할 수 있다.
- 얼굴과 주요 소품을 중앙에 두고, 상단과 좌우에 여백을 남긴다. PC·모바일에서 표시 비율이 달라 가장자리는 잘릴 수 있다.
- 하단에는 연한 그라데이션이 겹치므로 필수 정보나 글자를 그림에 넣지 않는다.
- 현재 변경은 대기실에 한정한다. 메인 로비의 일러스트·배치는 후속 시안에서 정한다.

## 확인

전체 Node 테스트 42개 통과. 격리된 Chromium으로 1440×900 / 1024×640 / 390×844 배치, 중복 AI 이름, 파트너 유지, 이모티콘, 게임 시작을 확인했다.

## UI 문구 기준

사용자 요청: 감성적인 슬로건이나 분위기를 꾸미는 문구를 넣지 않는다. 화면명·행동·상태가 바로 보이도록 `대기실`, `이모티콘`, `준비 완료`, `게임 시작`처럼 짧고 기능적인 표현을 사용한다. 기존 캐릭터 대사와 스킬명은 별도 콘텐츠이므로 이 기준으로 임의 수정하지 않는다.
