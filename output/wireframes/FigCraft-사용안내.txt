도둑잡기 와이어프레임 v0.7 / 2026-11-04

파일 열기
1. FigCraft의 File > Open에서 all-screens.svg를 엽니다.
2. 개별 화면만 열려면 svg 폴더의 W00~W15.svg를 사용합니다.
3. SVG는 도형과 텍스트를 포함합니다. 화면 그룹을 펼치거나 그룹 해제하여 편집합니다.
4. 필요하면 FigCraft에서 별도의 .figcraft 파일로 저장합니다.
5. 글꼴은 Windows 기본 Malgun Gothic(맑은 고딕)입니다.

전체 보드: all-screens.svg
화면별 원본: svg/ (16개)
정적 미리보기: png/ (16개), overview.png
화면 목록 및 검토 메모: screens.json

이 파일은 정적 와이어프레임입니다. 클릭 연결, 게임 로직, API 또는 DB는 구현하지 않았습니다.
PNG는 실제 SVG를 렌더링한 미리보기입니다. FigCraft에서 실제 가져오기 검증은 하지 않았습니다.
FigCraft 공식 문서가 SVG의 편집 가능한 프레임/도형/텍스트 가져오기를 지원한다고 명시합니다.
공식 문서: https://github.com/storytold/figcraft/blob/main/docs/cli.md

반영한 사용자 결정
- 중앙 버리는 구역은 상대 손패와 분리. 패가 많으면 펼침 간격을 줄여 지정 영역을 유지하며 중앙 구역을 침범하지 않음.
- 프로필은 정사각형 얼굴과 그 아래 닉네임(봇은 캐릭터명). 좌우 좌석 카드는 얼굴 옆에 가로로 눕혀 세로로 펼침.
- 테이블의 상대 손패는 장수 텍스트 대신 실제 장수만큼 펼친 뒷면 카드로 표시. 내 손패는 앞면 유지.
- 뽑기/결과 화면은 당사자 두 명에게만 노출. 다른 두 명은 테이블 대기.
- 자발적 공개 이모티콘은 정보 노출을 제한하는 대상으로 삼지 않음.
- 조작 단계마다 20초 후 자동선택. 연출 동안 타이머 정지.
- 선택 변경 클릭 때마다 갱신할지 여부는 확정 전이며 본 와이어프레임은 기능을 구현하지 않음.
- 마지막 조커 보유자만 패배. 나머지는 승리.
- 세트 종료 순서에 따라 +1000 / +500 / 0 / -500.
- B가 A의 마지막 카드를 뽑으면 A의 종료를 먼저 확정한 뒤 B의 페어를 처리.
- 여러 세트 합산으로 최종 순위 결정 후 랭크와 재화 지급. 후속 범위.
- 승리 후 관전 대기 허용. 차례 및 다음 세트 알림 위치만 제안.

기획서 작성 시 포함할 요구사항 (지금은 작성/개발하지 않음)
- 프론트엔드와 백엔드 분리.
- 시놀로지 NAS 서버 구동 및 배포 구성. NAS 모델/CPU/메모리/컨테이너 지원 확인 후 확정.
- 상세 DB 구조: 테이블/필드/자료형/PK/FK/제약/인덱스/관계/트랜잭션/마이그레이션.
- 사용자/캐릭터/보유품/호감도/매치/세트/참가자/점수/보상 원장 등을 검토.
- Swagger UI + OpenAPI 명세. 요청/응답/인증/오류/멱등성 및 화면 ID 연결.
- 실시간 게임 통신은 REST API와 구분하여 이벤트/권한/재접속 명세 작성.

후속 화면은 W13(스킬), W14(매치 정산), W15(캐릭터/상점)에 표시했습니다.
W01의 재화/랭크, W02의 여러 세트 구성 등 확장 연결 지점도 현재 구현을 뜻하지 않습니다.
캐릭터 일러스트는 위치만 표현한 자리표시자이며, 작혼/아스트랄 파티 자산을 사용하지 않았습니다.
