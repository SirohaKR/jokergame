라스트 원 · 도둑잡기 프로토타입 v0.3

실행
1. START.cmd를 실행합니다. Node.js 20 이상이 필요합니다.
   현재 PC에서는 설치된 Codex 번들 Node도 자동으로 찾습니다.
2. 브라우저에서 http://127.0.0.1:4173 을 엽니다.
3. 테이블에 앉기 → 캐릭터 선택 / 닉네임 → 게임 시작.
종료는 서버 터미널에서 Ctrl+C. 다른 컴퓨터에서는 Node.js를 설치하고 npm start 사용.
index.html 더블클릭 대신 위 로컬 서버를 사용하세요(ES modules).

구현된 범위
- 나 1명 + AI 3명, 53장 분배, 최초 자동 페어 제거, 수동 페어 버리기.
- 상대 마지막 카드 제공자 종료 우선, 빈 좌석 건너뛰기, 한 세트 순위/점수.
- 뽑기 / 뽑히기 / 비당사자 대기, 3초 결과 연출, 조작마다 20초 자동 진행.
- 정사각형 얼굴 + 하단 닉네임/캐릭터명 + 옆 카드, 중앙 구역 침범 방지.
- 모바일 세로 화면 전용 테이블, 손패/뽑기 카드 가로 스크롤.
- 터치 정렬: 순서 변경 → 카드 선택 → 좌우 버튼 → 정렬 완료.
- 대기 중 정렬 가능, 뽑기 당사자/자신의 페어 처리 중에는 정렬 잠금.
- 행동 후 페이지 및 카드 스크롤 위치 유지.
- 캐릭터 선택, 손패 드래그 순서 변경, 이모티콘, 효과음, 일시정지, 재시작.
- 선택 캐릭터 / 닉네임 / 효과음 설정 / 완료 세트 수는 브라우저 로컬 저장.
- 제공받은 캐릭터 4장의 투명 배경 PNG. 임시 이름 서하/오르카/하루/유나.

후속 범위 (미구현)
온라인 멀티, 로그인, DB 연결, 여러 세트 합산, 랭크/재화/상점/호감도, 캐릭터 스킬.
캐릭터별 웃음·당황·인사·의심 4종, 총 16종의 투명 이모티콘 구현. 조커 당사자에게 웃음/당황 반응과 효과음 제공. 스탠딩 자체의 얼굴 표정 교체는 후속 개발.
현재 브라우저 안에는 AI전 전체 상태가 있습니다. 온라인 보안 방식으로 사용할 수 없습니다.
