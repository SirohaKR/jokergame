# 로비 SVG 아이콘

대전 4종, 하단 메뉴 4종, 게임 방법을 위한 독립 SVG 9개입니다.
모든 파일은 80×80 viewBox, 3.2px 남색 외곽선, 흰색·스카이 면, 네이비 포인트를 사용합니다.
아래쪽에 단색 하늘색 그림자(feDropShadow, 흐림 0)를 둡니다.
배경 사각형, 그라데이션, 광택 하이라이트, 텍스처, 외부 이미지, 내장 PNG, 스크립트가 없습니다.
카드는 실제 트럼프처럼 모서리 숫자·무늬와 가운데 무늬를 그립니다(♥♦ 빨강, ♠ 남색).
이 프로젝트를 위해 직접 작성한 벡터이며 타 게임의 에셋을 복사하지 않았습니다.

각 의미와 색상은 manifest.json에 기록했습니다. AI대전은 로봇이 아닌
카드와 다트가 꽂힌 연습 과녁을 사용합니다. 친구대전(두 카드·방향)과 친구(두 사람)는
서로 다른 기호입니다. PNG 시안은 이전 검토 자료로 보존하지만 로비 메뉴에서 사용하지 않습니다.

## 수정과 이관

- 파일마다 독립적으로 색상과 경로를 수정할 수 있습니다.
- SVG는 배경이 투명합니다. 웹에서는 img로, 벡터 도구에서는 직접 열 수 있습니다.
- Unity에서는 프로젝트에 SVG 임포터가 있는 경우 스프라이트로 가져옵니다.
  임포터가 없으면 필요한 해상도의 투명 PNG로 내보내서 사용합니다.
- 버튼 배너·메뉴명은 SVG에 포함하지 않고 별도 UI 요소로 유지합니다.
