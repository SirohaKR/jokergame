# Game fonts

The selected typography uses **여기어때 잘난체 (Jalnan)** for headings and menus,
and **Pretendard** for supporting text. Font files are served locally, without
third-party font requests. Keep the accompanying license notices when shipping
the game or transferring these assets to Unity.
