# 라스트 원 · 도둑잡기

캐릭터 4명이 함께하는 도둑잡기 웹 프로토타입입니다. 현재 버전은 **나 1명 + AI 3명, 단일 세트**로 실행됩니다. 온라인 멀티플레이와 DB 연결은 아직 구현하지 않았습니다.

## 다른 PC에서 시작하기

Git과 Node.js 22 이상을 설치한 뒤 실행합니다. Windows, macOS, Linux에서 같은 명령을 사용할 수 있습니다.

```sh
git clone https://github.com/SirohaKR/jokergame.git
cd jokergame/prototype
npm start
```

브라우저에서 <http://127.0.0.1:4173/>에 접속합니다. 현재 외부 npm 의존성이 없어 `npm install`은 필요하지 않습니다. Windows에서는 `prototype/START.cmd`를 실행해도 됩니다. 서버 종료는 `Ctrl+C`입니다.

```sh
# prototype 디렉터리에서 게임 규칙 및 서버 테스트
npm test
```

기획서는 <http://127.0.0.1:4173/docs/>, Swagger UI는 <http://127.0.0.1:4173/docs/api.html>입니다. Swagger UI 라이브러리는 인터넷에서 불러옵니다. 현재 실제 API는 `/api/health`뿐이며 나머지 온라인 API는 설계 계약입니다.

## 개발을 이어가기 전에

**[개발 인수인계](docs/DEVELOPMENT.md)**를 먼저 읽으세요. 확정된 게임 규칙, 화면/정보 공개 범위, 수정 이력, 다음 개발 항목을 기록했습니다. Codex 등 다른 도구에서 이 저장소를 열고 이 문서를 읽도록 요청하면 대화 기록 없이도 이어갈 수 있습니다.

```sh
# 다른 PC에서 작업 전 최신 변경 받기
git pull --ff-only
# 작업 후 변경 기록과 업로드
git add .
git commit -m "변경 내용"
git push
```

## 캐릭터·세계관 기획

- [캐릭터 감성·셀 채색 방향](docs/ART-DIRECTION.md): 참고 작품별 검토 방향과 선화·명암 기준

- [캐릭터 설정집](docs/CHARACTERS.md): 네 여성 캐릭터의 성격·외형·과거·대사·관계와 스킬 콘셉트
- [세계관](docs/WORLD.md): 마도도시 루미에르, 주점 ‘별의 끝’, 마법과 카드놀이 문화
- [스킬·PixAI 제작 가이드](docs/CHARACTER-DESIGN.md): 스킬 판정 초안, 이미지 생성 프롬프트, Live2D 준비 조건

세레나·엘리시아·루네아·로제트의 스탠딩과 16종 이모티콘을 게임에 적용했습니다. 설정 문서의 스킬과 호감도 이야기는 후속 개발 범위입니다.

## 구성

- `prototype/frontend/`: HTML/CSS/JavaScript, 캐릭터 스탠딩 및 이모티콘 자산
- `prototype/backend/`: Node HTTP 서버
- `prototype/tests/`: Node 내장 테스트 러너용 테스트
- `prototype/docs/`: 상세 기획서, PostgreSQL DDL, OpenAPI 계약
- `prototype/deploy/`: Synology Container Manager용 Docker 초안
- `docs/reference/`: 사용자가 제공한 원안 PDF
- `output/wireframes/`: FigCraft용 SVG, 화면 목록 및 미리보기

## 현재 기능

53장 덱, 페어 버리기, 20초 행동 제한, AI 대전, 결과 순위/점수, 당사자 전용 뽑기 연출, 캐릭터별 이모티콘 16종, 모바일 세로 테이블과 터치 손패 정렬을 구현했습니다.

닉네임/선택 캐릭터/설정은 기기별 브라우저에 저장됩니다. 진행 중인 게임과 설정이 다른 PC로 자동 이전되지는 않습니다. 기존 임시 공개 링크는 원래 PC의 서버와 터널에 연결되어 있어 저장소를 복제한다고 유지되지 않습니다.

NAS 실제 배포, DB 적용, 로그인, 온라인 멀티플레이, 여러 세트 합산, 랭크/재화/스킬은 후속 개발 범위입니다. 캐릭터명은 임시 이름이며 이미지 권리나 재배포 라이선스를 이 저장소에서 새로 부여하지 않습니다.

## UI 배치 편집기

게임 로비의 **UI 편집** 또는 <http://127.0.0.1:4173/editor.html>에서 엽니다. PC 브라우저 사용을 권장합니다.

- 로비·대기실·게임 테이블의 배치 초안을 각각 편집합니다. 실제 게임 DOM을 직접 편집하는 기능은 아닙니다.
- 왼쪽 요소/캐릭터 에셋을 끌어 넣거나 클릭해 추가하고, 캔버스에서 이동·모서리 크기 조절을 합니다.
- 오른쪽 속성에서 좌표·크기·텍스트·색상·이미지 맞춤·회전·불투명도를 지정합니다. 레이어 순서 변경, 복제, 숨김, 위치 잠금도 지원합니다.
- PNG/JPG/WebP(3MB 이하)를 업로드할 수 있습니다. 업로드 이미지는 JSON에 함께 저장됩니다.
- 방향키는 1px, Shift+방향키는 10px 이동. Ctrl/Cmd+Z는 실행 취소, Ctrl/Cmd+Shift+Z는 다시 실행, Ctrl/Cmd+D는 복제입니다.
- 브라우저에 자동 저장됩니다. 다른 PC로 전달하거나 백업하려면 **JSON 저장**을 사용하세요. **불러오기**로 계속 편집할 수 있습니다.
- 전달 시 **JSON(세 화면 + 수정 메모)과 PNG(현재 화면)**를 함께 보내 주세요. 기본 캐릭터 에셋은 저장소 파일 경로로 연결되므로 같은 저장소에서 엽니다.
- 편집 결과는 배치 제안서입니다. 게임 동작 연결·반응형 규칙·Unity 적용은 전달받은 배치를 기준으로 별도 구현합니다. 캔버스 크기를 바꿔도 기존 요소 위치를 자동 재배치하지 않습니다.

### 제목으로 기획 보관하기

편집기 상단의 제목을 입력하고 **기획에 저장**을 누르면 로비·대기실·게임 테이블과 메모가 한 기획안으로 저장됩니다. 아래 **UI 디자인 기획 보기** 또는 게임 로비의 **UI 디자인 기획**으로 목록을 열 수 있습니다. 저장 완료 후 **방금 저장한 와이어프레임 보기**로 바로 확인할 수도 있습니다.

목록에서 기획안을 고르면 세 화면의 와이어프레임, 수정 메모와 요소별 좌표·크기를 확인합니다. **편집기로 열기**로 수정하고 다시 저장하면 기존 기획안은 보존되고 새 항목이 추가됩니다. JSON 및 화면별 SVG도 내려받을 수 있습니다.

기획안은 서버의 `output/ui-designs/`에 JSON 파일로 보관되어 서버를 다시 실행해도 유지됩니다. 같은 서버에 접속하면 다른 브라우저에서도 목록을 볼 수 있습니다. 브라우저 자동 저장은 편집 중 초안이며, 기획 목록에는 **기획에 저장**을 누른 내용만 추가됩니다. 다른 PC의 별도 서버나 GitHub로 자동 동기화하지는 않습니다. `UI_PLANS_DIR`로 저장 경로를 지정할 수 있고, Docker Compose는 `ui-designs` 볼륨에 보관합니다.

## 대사 스튜디오

게임 로비의 **대사 편집** 또는 <http://127.0.0.1:4173/scripts.html>에서 엽니다.

- 왼쪽에서 캐릭터를 고르고, 가운데에서 상황별 대사(등장·호감·스킬 발동·이모티콘 말풍선 4종·뽑기 반응 4종·결과 2종)를 씁니다. 처음에는 지금 게임에 들어간 대사와 `docs/CHARACTERS.md`의 대사로 채워져 있습니다.
- 칸마다 **게임 반영 중**(지금 게임이 캐릭터별로 표시) / **게임은 공통 문구**(지금은 모든 캐릭터가 같은 문구) / **기획용**(아직 게임에 연결 안 됨) 표시가 붙어 있습니다.
- 정해진 칸 밖의 대사는 **상황별 추가 대사**에 상황·대사·표정·연출 메모로 적습니다. 캐릭터별 말투 메모도 남길 수 있습니다.
- 칸을 누르면 오른쪽 미리보기에 스탠딩과 말풍선(스킬은 컷인)으로 보여 줍니다.
- 브라우저에 자동 저장됩니다. **JSON 저장/불러오기**로 백업·전달하고, **대본 문서(.md)**로 읽기 쉬운 대본을 내려받습니다.
- 제목을 쓰고 **대본에 저장**하면 서버 `output/scripts/`에 버전별로 보관되어 오른쪽 목록에서 다시 열 수 있습니다. `SCRIPTS_DIR`로 경로를 바꿀 수 있습니다.
- 편집 결과는 게임 대사를 자동으로 바꾸지 않습니다. 전달받은 JSON/문서를 기준으로 게임에 옮깁니다.
